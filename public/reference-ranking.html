选型结论

针对「个人主页 + 博客 + 导航/工具、中文内容、颜值高 + 省心 + 快、不租服务器」这组目标：

底座
Astro 7.3.2
产物是纯静态 HTML，任何免费平台都能直接托管，不挑部署环境；Islands 架构让你先写纯 HTML/CSS 再按需加交互。三项目标（颜值/省心/快）里唯一能同时拉满的。
视觉参考
fuwari + astrowind
fuwari 是 Astro 生态颜值最高的博客主题，卡片布局直接抄；astrowind 的 Tailwind 组件体系最完整，省得从零造轮子。
Obsidian 用户专属
Quartz
直接把 Obsidian 知识库变成网站的数字花园生成器，13.2k star。你已经在用 Obsidian 做第二大脑，这条路径能让笔记零成本上线——值得单独评估。
必备组件
Giscus + Pagefind
评论用 Giscus（12.1k），零服务器、靠 GitHub Discussions 托管；搜索用 Pagefind，构建期生成静态索引。两个都不需要后端，完全贴合"不租服务器"。

国内免费部署已排除的平台（免备案 + 三级域名 + 国内可访问，三个条件卡掉的）

  • 阿里云 OSS / 华为云 OBS / 七牛云 / 又拍云 —— 默认域名是四级或更长，且静态网站托管强制绑定已备案自定义域名
  • Vercel / Netlify —— 赠送域名是三级，但国内 DNS 被污染，无法直连；只能当海外站
  • Gitee Pages —— 域名是三级（用户名.gitee.io），但个人免费版需实名认证且没有自动构建，更新次数受限
  • agentos-app 类平台 —— 赠送的是四级长域名（如 随机串.sh1.agentos-app.net），层级太低

✅ 唯一同时满足四个条件的是 腾讯云 EdgeOne Pages：xxx.edgeone.app（三级）、长期免费、免备案、国内节点秒开、原生支持 Astro 自动构建。
